# 音集 MusicHub — 桌面音乐应用

Electron 桌面应用，深色玻璃拟态界面，单文件渲染层，零 API 密钥。

## 界面
- 自绘无边框标题栏（最小化 / 最大化 / 关闭）
- 左侧栏：搜索框 + 发现音乐 / 我的收藏 / 本地音乐 / 播放队列四个视图
- 主区：歌曲列表（封面、标题、艺人、专辑、时长、收藏）
- 底部播放条：播放/暂停、全部播放、上一/下一、随机、重复、进度拖动、歌词开关、音量/静音
- 播放中的歌曲行内显示动态均衡器，队列视图顶部显示「正在播放」横幅
- 歌词面板：右下角浮层，随播放进度实时高亮当前行

## 功能
- 🔍 搜索（中英文均可，自动防抖 450ms）
- ▶️ 发现音乐：网易云**整首在线播放**（免 key），每页 50 首 + 「加载更多」分页（官方 API，真分页无重叠）
- ▶️ 全部播放：一键把当前列表整页放进队列并从第一首连播
- 📜 歌词：点击播放条「歌词」按钮，面板随进度实时高亮（在线歌走网易云 LRC，本地歌读同名 .lrc）
- 💿 本地音乐：选一个文件夹即可**整首播放、可拖动进度**（mp3/flac/m4a/aac/ogg/wav/opus/wma，递归子目录）
- 🎧 队列管理 + 自动切歌 + 随机/重复
- 💗 收藏（localStorage 持久化，本地与在线均可收藏）
- ⌨️ 快捷键：空格=播放/暂停，Ctrl+←/→=切歌，F11=全屏

## 结构
- `main.js` — Electron 主进程（无边框窗口、IPC 窗口控制、本地音乐扫描、网易云在线整曲 IPC）
- `preload.js` — contextBridge 暴露窗口控制 + 本地音乐库 + 网易云在线整曲（netSearch/netPlayUrl/netLyric）
- `index.html` — 全部 UI + 逻辑（搜索/播放/全部播放/队列/收藏/本地库/歌词面板）

## 技术说明
- 发现音乐搜索: `https://music.163.com/api/search/get?s=...&limit=50&offset=...`（网易云官方 API，真分页）
- 封面: `https://music.163.com/api/song/detail?ids=[...]` 批量一次取整页专辑封面
- 整曲播放: `https://api.qijieya.cn/meting/?type=song&id=...` → 302 到网易云 CDN 整曲 mp3，`<audio>` 流式播放（主进程解析 Location 地址）
- 在线歌词: `https://api.vkeys.cn/v2/music/netease/lyric?id=...`（LRC 格式）
- 本地歌词: 音频同目录同名 `.lrc` 文件
- 本地音频: `file://` 源播放本地文件（同源，支持整首 + 拖动进度）
- 整曲地址经第三方解析代理提供，仅供学习/个人使用，版权归各平台与原作者
